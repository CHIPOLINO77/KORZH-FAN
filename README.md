# KORZH FAN

Независимый фанатский проект для сообщества слушателей Макса Коржа.

## MVP
- адаптивный dark-first интерфейс;
- интерактивный тест «На сколько ты Корж?»;
- 7 вопросов и несколько фанатских архетипов;
- результат 0–100;
- шаринг результата через Web Share API или копирование ссылки;
- UTM-friendly URL;
- разделы фанатов, историй и концертов;
- без OpenAI API и без серверной части.

## Запуск
Открой `index.html` локально или включи GitHub Pages для ветки `main`.

## Важно
KORZH FAN — независимый проект. Он не является официальным сайтом и не связан с Максом Коржом или его командой. Не размещаем тексты песен, полные записи или материалы, на которые нет прав.
